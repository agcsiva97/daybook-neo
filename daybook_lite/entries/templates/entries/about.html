Daybook

Day-to-day floor operations for your shop staff

  • Log debit & credit transactions with real-time balance checks
  • Loan & release entries, including fast bulk pawn entry
  • Cash denomination counting by shift (morning / afternoon / evening / night)
  • Daily shop report with opening & closing balances
  • Full transaction & loan edit history for every entry
  • Export transactions to CSV or Excel anytime

Manager

Admin console for owners & auditors

  • Set up shops, ledgers, account groups & chart of accounts
  • Balance sheet, trial balance & group-type summaries
  • Multi-year networth trend across all shops
  • Shop-to-shop transaction sync via import / export
  • Complete activity log of every create, update & delete
  • Central configuration — session timeout, default shop, backups

Data & Security

Built in, no setup required

  • Every transaction & loan keeps a full audit trail — who changed what, and when
  • Activity log tracks every create, update & delete across the app
  • Debit entries are blocked automatically if a shop has insufficient balance
  • Role-based access — Staff, Admin & Super Admin see only what they should
